### Project and reproducible behavior
ProofPass is a course-project digital-credential application using Ethereum Sepolia (chain ID 11155111). It supports credential issuance, verification, correction/revocation, and two-of-three institution governance.

1. Open https://vinzch.github.io/proofpass/upgrade/ in Chrome with MetaMask Extension.
2. Click “连接钱包” (Connect wallet).
3. The website warning was displayed before account connection. The user later continued manually; that does not establish that the domain classification has been cleared for other users.

The host root https://vinzch.github.io/ currently returns 404 because this is a GitHub Pages project site. The actual /proofpass/ and /proofpass/upgrade/ application URLs return 200. Please review the full application path.
