# ProofPass

一个在 AI 辅助下完成的 Web3 课程项目，围绕数字凭证的签发、保存和核验展开。

这是我第一次比较完整地接触 Web3。我想借这次课程项目，把一个网页、浏览器钱包和智能合约真正连接起来，尝试跑通从签发凭证到链上核验的流程，也逐步理解钱包地址、交易、Gas、合约权限，以及链上与链下数据之间的关系。

开发过程中，我使用 AI 辅助梳理思路、编写和调整代码、排查问题及整理文档。这个仓库记录的是一次边做边学的尝试。目前项目运行在 Sepolia 测试网，主要用于课程学习与演示。

**[打开在线网站](https://vinzch.github.io/proofpass/)**

## 做了什么

- **签发凭证**：由获得机构签发权限的钱包登记凭证，下载对应的 JSON 凭证文件。
- **核验凭证**：导入文件，检查内容摘要、有效期和链上状态；查询与核验无需连接钱包。
- **管理版本**：支持凭证更正、撤销，以及历史版本关系查询。
- **管理机构**：支持机构登记、启用或停用，以及签发钱包的更换。
- **尝试多账户治理**：通过提案、投票和执行处理机构权限等操作，采用三个治理账户、至少两票通过的规则。当前演示使用本人 MetaMask 中的三个账户。

## 用到的技术

| 部分 | 技术与用途 |
| --- | --- |
| 网页界面 | HTML、CSS、原生 JavaScript ES Modules |
| 合约交互 | ethers.js 6.17.0，连接钱包、调用合约和读取链上数据 |
| 智能合约 | Solidity 0.8.38，管理凭证状态、机构权限与治理提案 |
| 区块链网络 | Ethereum Sepolia 公共测试网，通过 JSON-RPC 查询数据 |
| 钱包 | MetaMask，用于账户连接和交易确认 |
| 内容校验 | Web Crypto API / SHA-256，生成并核对凭证内容摘要 |
| 凭证文件 | JSON，保存凭证内容并支持导入、下载 |
| 网站托管 | GitHub Pages，发布静态网页 |

标题、持有人代号等内容保存在凭证文件中，链上保存摘要、有效期、状态和版本关系等信息。网页读取文件后重新计算摘要，再与合约记录比对。

## 在线使用

打开网站即可查询和核验凭证。需要签发或进行治理操作时，连接 MetaMask 并切换到 **Sepolia**；签发需要相应机构权限，发送交易需要少量 Sepolia 测试币。

- 网络：Ethereum Sepolia（Chain ID：`11155111`）
- 合约：[`0x623b2e6a55003da0aa144ef0ec53547af3f61410`](https://sepolia.etherscan.io/address/0x623b2e6a55003da0aa144ef0ec53547af3f61410)

## 本地运行

本仓库保存的是网站的静态发布文件，包含前端代码、合约 ABI 和网络配置。安装 Python 3 后，可以直接启动本地服务，无需安装 npm 依赖或进行构建：

```bash
git clone https://github.com/VinZch/proofpass.git
cd proofpass
python3 -m http.server 8080 --bind 127.0.0.1
```

然后访问 [http://127.0.0.1:8080/upgrade/](http://127.0.0.1:8080/upgrade/)。

```text
proofpass/
├── index.html       # 网站入口
├── upgrade/         # 工作台界面、业务逻辑、合约 ABI 和配置
└── chain/           # 共用链连接、凭证协议工具和 ethers.js
```
